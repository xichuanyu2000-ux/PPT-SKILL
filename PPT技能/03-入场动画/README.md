# 入场动画：pptx-animation

- 来源：https://github.com/Yusong-Enceladus/pptx-animation-skill
- 上游版本：a88ccf628cda814be55435d751aa6971f48b064e
- 技能入口：pptx-animation/SKILL.md
- 收录：完整技能目录，包含参考文档、Python 脚本和原始 MIT 许可证。

## 效果

给现有 PPT 添加按点击逐组淡入，例如一整列图文或一个完整流程步骤同时出现。上游默认跳过封面、分隔页和结尾页。

## 使用

先准备现有 PPT 的副本，然后按 SKILL.md 中的脚本流程识别分组、检查分组、注入动画。默认文件处理方式需要 Python；具体依赖以脚本和上游说明为准。AppleScript 方案仅适用于 macOS，本仓库不把它当作 Windows 方案。

最终需要在实际放映软件中验证动画节奏。本次只收录文件，未运行脚本。
