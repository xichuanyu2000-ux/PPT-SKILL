## baoyu-image-gen

入口：baoyu-image-gen/SKILL.md

生成背景、封面、插图等静态图片。支持的服务及配置以技能说明为准；部分服务需要账号、API 凭据和费用。不要把密钥或私人配置提交到本仓库。

## baoyu-slide-deck

入口：baoyu-slide-deck/SKILL.md

从内容生成大纲和整页幻灯片图片，并可将图片合成 PPTX/PDF。视觉风格资料、提示词规范和合并脚本均一并保留。

图片式幻灯片不等于逐项可编辑的文字、图表。它适合视觉方案探索和阅读分享；动态效果需要配合其他工具。

## 使用

保持两个目录并列，按各自 SKILL.md 选择运行环境、图像服务和偏好配置。该集合通常需要 Node.js 与 Bun/npx；不因本次收录而自动安装依赖、配置服务或调用付费 API。
