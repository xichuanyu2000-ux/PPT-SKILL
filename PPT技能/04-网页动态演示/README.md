## 效果

生成浏览器播放的 HTML 演示，支持多种视觉风格和 CSS/JS 动画，先比较风格预览再制作完整内容。

## 使用

将完整 frontend-slides 文件夹交给支持读取技能的 AI 工具。保留目录结构，不要只复制 SKILL.md。演示成品主要是 HTML，并非保证可以在 PowerPoint 中逐项编辑的 PPTX。

浏览器播放与 PDF 导出是不同流程，导出的 PDF 为静态页面；转换既有 PPT 需要额外依赖，具体见技能说明。本次未运行或安装。
