# PPT技能

按 6 类整理前面讨论的 7 个技能，用于可编辑 PPT、动态转场、网页演示、视频动效和视觉素材。整理日期：2026-10-21。

| 分类 | 技能 | 用途 |
|---|---|---|
| 01-可编辑PPT | Anthropic pptx | 创建、读取、编辑 PowerPoint；受上游授权限制，仅提供来源入口与使用说明 |
| 02-平滑转场 | morph-ppt + officecli-pptx 配套 | 文字、图片和图形跨页移动、缩放、旋转 |
| 03-入场动画 | pptx-animation | 按点击逐组淡入现有 PPT 内容 |
| 04-网页动态演示 | frontend-slides | 制作浏览器中播放的 HTML 动画演示 |
| 05-视频动效 | Remotion Skills | 编排动态标题、视频背景、音频和时间轴 |
| 06-视觉素材 | baoyu-image-gen、baoyu-slide-deck | 生成背景图片和图片式幻灯片 |

## 选择方式

- 需要可编辑文字、图表：优先 01。
- 需要文字或图片在翻页时连续变化：优先 02。
- 需要按讲解节奏逐组出现：优先 03。
- 需要网页播放、分享动画演示：优先 04。
- 需要类似抖音的动态结尾片段：优先 05，另准备海浪、帆船等视频素材。
- 需要漂亮的背景与风格探索：优先 06。

## 使用与来源

各分类下的 README.md 记录技能入口、上游地址、版本和依赖。保留上游技能目录及其配套文件，不代表已安装其运行环境，也不代表已经实测所有效果。外部 API 可能需要独立账号和费用。

海浪、帆船的持续运动需要动态素材；Morph 转场负责跨页元素变化，不能把一张静态海浪图片自动变成真实海浪视频。

上游文件遵循各自许可证。此目录不使用一个统一许可证覆盖第三方内容。
