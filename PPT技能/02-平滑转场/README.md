## 效果

在连续页面之间让相同元素平滑移动、缩放、旋转或改变透明度。适合产品展示、章节切换和动态结尾；真实海浪等自然运动需要另配视频素材。

## 使用

保持 morph-ppt 与 officecli-pptx 两个目录并列。先阅读基础技能，再阅读 Morph 技能。需要另行安装 OfficeCLI，具体安装方式见上游官方文档：https://github.com/iOfficeAI/OfficeCLI 。

在最终放映软件中验证转场。不同 PowerPoint、WPS、Keynote 或其他软件版本的播放行为可能不同。
